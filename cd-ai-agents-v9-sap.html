Automated Release Workflow — How BRH Decides
⚙️
① Production Complete
Agent 08 signals batch completion in SAP Digital Manufacturing. Production order closed, material consumption confirmed, OEE recorded for the run.
🔬
② QC Sampling & CoA
Lab results (pH, viscosity, microbial, label check) posted to SAP QM. Certificate of Analysis generated. In-process quality data from Agent 08 pre-populates the CoA template.
🤖
③ BRH Auto-Decision
BRH evaluates all spec criteria against defined release rules. If all pass → auto-release to unrestricted stock. If any fail → exception routed to QA reviewer queue within 2 minutes.
⚖️
④ Compliance Cross-Check
Agent 05 compliance status checked in real time. Any open regulatory holds, label violations, or market-specific non-compliance blocks release — even if QC specs pass. Both gates must clear.
✅
⑤ Released → Available
Batch posted to unrestricted inventory in S/4HANA. Agent 06 picks up the new available supply within 5 minutes via IBP sync and updates PAL allocation quotas accordingly.
SAP BRH Key Capabilities — Relevant to C&D
📋 Rule-Based Auto-Release
Define spec criteria (pH range, viscosity, fill weight, microbial limits) per SKU or product family. BRH automatically releases batches that meet all criteria — no manual QA sign-off required, reducing cycle time from days to hours. C&D target: auto-release ≥ 85% of batches.
🔗 Agent 05 Integration — Dual Gate
BRH checks SAP Product Compliance status for every batch before release. A label change flag or regulatory hold from Agent 05 (e.g. EPA rule update affecting Arm & Hammer) automatically blocks the release — even if every QC spec passes. Prevents non-compliant product from entering the supply chain.
🤖 AI Vision Label QC
Agent 08's AI Vision computer vision system (99.1% accuracy) feeds label defect scores directly into BRH. A label with incorrect lot number, wrong barcode, or missing regulatory text triggers an automatic hold in BRH before the batch is released — zero non-compliant units reach the DC.
📄 Digital CoA Generation
BRH auto-generates the Certificate of Analysis from in-process quality data and lab results. CoA is electronically attached to the batch in S/4HANA and shared with retailers on request via SAP Business Network — eliminating the manual CoA process that currently takes 1–2 days per batch.
⏱ Release → Allocation Signal
Once BRH releases a batch to unrestricted stock, a real-time event triggers Agent 06 to recalculate available supply and re-run PAL quota allocation. Released volume becomes orderable within 5 minutes — versus the current T+1 day lag when planners manually update the supply plan after QA sign-off.
🌍 Multi-Market Release Rules
C&D sells across 130+ markets with different label, ingredient, and regulatory requirements. BRH manages market-specific release rules — a batch destined for the EU may require different compliance gates than one destined for the US. Agent 05's 130-market rule engine feeds directly into BRH's release criteria matrix.

What Is This File?

A prototype of an Autonomous Supply Chain Operations Center — built specifically on Church & Dwight's brand portfolio, supplier base, SAP system estate, and commercial structure.

Church & Dwight manages 12+ consumer brands (ARM & HAMMER, OxiClean, Vitafusion, Batiste, First Response, Nair, Spinbrush, and others) across ~1,240 SKUs, sold through major US and international retailers. Today, supply chain monitoring, demand sensing, trade promotion analysis, supplier risk, and manufacturing performance are tracked manually — across disconnected SAP modules, spreadsheets, and weekly reports. By the time an anomaly surfaces in a report, the response window has often already closed.

This file shows what it looks like when 8 AI agents — powered by SAP Joule Agentic AI on BTP — continuously monitor that same data, detect anomalies in real time, and surface prioritized actions to the right teams. Every number, alert, and recommendation in this demo is modelled on realistic C&D structures to make the business case concrete and specific.

What does the Business Network agent (Agent 07) monitor? ▼
Agent 07 monitors SAP Business Network (formerly Ariba Network) for four collaboration workflows: (1) PO Confirmation — tracks whether suppliers confirm purchase orders within 48 hrs and flags latency or non-confirmations; (2) ASN Tracking — monitors Advance Shipment Notices for timeliness and gaps in in-transit visibility; (3) Invoice Intelligence — performs 3-way match (PO · GR · Invoice) via S/4HANA MM and auto-flags price deviations, quantity mismatches, and duplicate invoices; (4) Supplier Onboarding — tracks which suppliers are connected to the Business Network and drives onboarding campaigns to raise coverage. Go to the 🌐 Business Network tab for the full view.
How does the Allocation Intelligence agent (Agent 06) work? ▼
Agent 06 orchestrates the full allocation lifecycle: SAP IBP for Response & Supply creates constrained allocation plans by product, plant, customer group, and time bucket. SAP S/4HANA aATP enforces those quotas in real time on every sales order via Product Allocation (PAL), Backorder Processing (BOP), and Supply Protection (SUP). Joule Agentic AI on SAP BTP monitors quota depletion, triggers BOP re-runs, recommends dynamic reallocation shifts, and writes updated PAL quantities back to S/4HANA via OData API. Go to the 📦 Allocation Intelligence tab for the full view.
